# Branch Retirement Contract

Require all of:

- exact run-branch parser and run ID;
- `VERIFIED` independent decision;
- permitted objective class;
- PR `closed && merged`;
- selected repository as head repository;
- exact repository/base/branch/head-SHA/PR-number binding;
- corresponding queued finding;
- immediate authenticated event trigger plus periodic reconciliation;
- explicit preservation of historical and non-terminal evidence.

Deletion failure never changes verification state.
